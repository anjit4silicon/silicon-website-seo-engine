# Changelog

## 0.3.0 — Unreleased

- Next.js published and draft bindings, metadata, sitemap, and revalidation.
- Reusable basic dashboard editor and starter SEO report.
- Site-local sign-in with durable attempt limiting and a complete example app.

## 0.2.0 — Database foundation

- PostgreSQL storage for pages, revisions, users, settings, and media.
- Numbered database migrations with checksums.
- Resumable initial-content import.
- Explicit page schema versions and guarded content migration.

## 0.1.0 — Foundation

- Initial site and page definition API.
- Built-in field validation and custom field validators.
- Storage adapter contract with optimistic revision checks.
- Draft and published content operations.

This is an internal foundation release. It does not include the dashboard, SEO analysis, or a persistent storage adapter.
